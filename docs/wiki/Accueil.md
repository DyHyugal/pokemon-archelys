# Pokémon Archélys

Une nouvelle aventure dans un archipel original, pensée pour être parcourue seul ou jusqu’à trois joueurs.

Le projet est actuellement en conception. Aucun téléchargement jouable n’est disponible. Le rendu visé est une 3D stylisée en Full HD ; les premiers essais serviront à valider la présentation et le fonctionnement du jeu.

Consulter la [roadmap](Roadmap.md) pour suivre l’avancement et la rubrique [Jouer](Jouer.md) pour connaître la disponibilité des versions de test.
