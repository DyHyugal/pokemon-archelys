# Jouer au laboratoire technique

Une [prerelease Windows de laboratoire](https://github.com/DyHyugal/pokemon-archelys/releases/tag/lab-09897ca) est disponible. [Télécharger le ZIP](https://github.com/DyHyugal/pokemon-archelys/releases/download/lab-09897ca/Archelys-Laboratoire-Windows.zip), le décompresser entièrement et ouvrir Archelys-Laboratoire.exe ; aucune installation de Godot n’est nécessaire.

Il s’agit d’un essai de faisabilité avec décors et mannequin provisoires. Aucun Pokémon final ni histoire n’est disponible ; l’export a réussi, mais son exécution sous Windows reste à tester. Ce n’est pas la démo de la première île ni une validation du rendu final.

Les contrôles et limites sont décrits dans le LIRE-MOI du ZIP. Le réseau du laboratoire est localhost : trois fenêtres sur le même PC, pas encore entre deux PC. La configuration minimale sera déterminée plus tard. Le jeu ne nécessite pas de ROM.

Les sauvegardes des premiers prototypes peuvent être réinitialisées. Le laboratoire indique son fichier et sa copie précédente dans le LIRE-MOI. À partir de l’alpha publique, les migrations et la restauration seront expliquées avec le format final.

Cette page est une source documentaire du dépôt ; elle n’est pas encore publiée automatiquement dans un wiki joueurs.
