# Jouer

Aucune version jouable n’est disponible pour le moment. Les premiers tests seront distribués sous forme de ZIP Windows : extraire les fichiers puis lancer l’exécutable, sans installation de Godot.

La configuration minimale sera indiquée après les mesures de performance. Le jeu ne nécessite pas une ROM de base et n’est pas une ROM GBA.

Les sauvegardes des premiers prototypes pourront être réinitialisées, avec avertissement. À partir de l’alpha publique, les mises à jour prévoiront conversion et copie de secours ; l’emplacement de ces copies et leur restauration seront expliqués ici lorsque le format existera.
