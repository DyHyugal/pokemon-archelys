INSTALLATION ET BLOCAGE WINDOWS
Décompresser entièrement le ZIP dans un dossier, puis ouvrir
Archelys-Laboratoire.exe. Aucune installation de Godot n'est nécessaire.
Il s'agit d'un prototype Windows 64 bits, pas d'une ROM.
Cette variante portable contient un moteur Godot non modifié et un fichier
Archelys-Laboratoire.pck séparé contenant le jeu. Garder les deux fichiers
dans le même dossier ; ne pas lancer l'EXE depuis l'intérieur du ZIP.
Aucune signature reconnue ni autorisation Windows n'est ajoutée.
Le Contrôle intelligent des applications peut donc encore bloquer le lancement.

PREMIER TEST DE CETTE LIVRAISON
Essayer d'abord de lancer normalement Archelys-Laboratoire.exe, sans modifier
les réglages de sécurité Windows. Si Windows le bloque encore, noter simplement
« lancement bloqué par le Contrôle intelligent » : les tests en jeu attendront.
S'il démarre, vérifier le parcours complet ci-dessous. Le propriétaire a
confirmé que la variante portable précédente lançait le jeu sans avertissement
sur son PC. Le moteur de ce build reste identique ; les données ont évolué.


Si l'écran indique « Windows a protégé votre ordinateur » et propose
« Informations complémentaires », cliquer dessus puis « Exécuter quand même »
si tu choisis d'exécuter ce build téléchargé depuis la release du dépôt.
Une autre possibilité, quand Windows la propose : clic droit sur le fichier,
Propriétés, cocher « Débloquer », puis Appliquer. Cela ne signe pas le programme.

Ces options ne sont pas disponibles dans tous les cas. Smart App Control,
une politique d'entreprise ou une détection antivirus sont des situations
différentes : ne pas désactiver globalement la protection. Dans ce cas, noter
le texte exact de l'écran et le nom de la protection pour diagnostiquer le blocage.

Une signature reconnue exige un certificat de signature de code ou un service
de signature autorisé. Aucun n'est configuré pour ce projet actuellement.
Une signature auto-signée ne suffit pas pour être reconnue sur ton PC.

ESSAI SANS MODIFIER TA PARTIE
Activer Outils labo avec F3 et cliquer Essai zones / Abri / soutien
(sans sauvegarde). L'écran indique ESSAI SANS SAUVEGARDE. L'équipe temporaire
est Tortank, Florizarre et Dracaufeu niveau50 ; ta vraie équipe, ton argent,
ton sac et ton Pokédex ne sont pas remplacés. Les nouveaux boutons indiquent
clairement qui sera touché. Les textes avancent toujours manuellement.

Choisir Surf pour Tortank, puis Abri pour Florizarre. Les choix attendent
tous les deux avant le tour. Florizarre utilise Abri avant Surf : il reste
protégé, les adversaires sont touchés. Surf ne touche pas son utilisateur,
mais touche l'allié non protégé. Recommencer sans Abri permet de le constater.

Choisir Éboulement : il touche les deux adversaires sans toucher l'allié.
Tranch'Herbe fait également partie des attaques visant les adversaires.
Une attaque de zone consomme un seul PP, avec précision et effets distincts
par cible. Si plusieurs cibles vivantes sont présentes, dégâts réduits à75%.
Abri répété peut échouer : ce n'est pas un bug, ses chances sont divisées
par3 à chaque réussite successive, jusqu'à1/729. Il expire à la fin du tour
et ne supprime pas les dégâts résiduels comme le poison. Abri échoue aussi
si son utilisateur est le dernier Pokémon à agir pendant le tour.

Choisir Surf pour Tortank puis Coup d'Main pour Florizarre : le soutien se
fait avant l'attaque et augmente sa puissance de50% pour ce tour. L'allié
subit Surf s'il n'utilise pas Abri. Coup d'Main ne fonctionne pas en simple.
Les attaques individuelles comme Vibraqua permettent aussi de cibler ALLIÉ :
attention, ce choix inflige réellement des dégâts à ton allié.

Le bouton Terminer l'essai sans changer la partie sort du combat. Relancer
l'essai le remet à zéro. Une victoire ou défaite dans cet essai ne change
pas la vraie campagne. Pas de sauvegarde possible en plein combat.
Ces mécaniques fonctionnent aussi hors essai ; les CT compatibles sont
disponibles depuis le résumé, sans nouvelles attaques imposées aux Pokémon
de tes anciennes sauvegardes. Le catalogue est désormais17 espèces/42attaques.

VOLUMES ET SONS D'ESSAI
Les trois curseurs règlent Général, Musique et Effets. Général affecte les
deux catégories ; chaque catégorie a ensuite son propre volume. Zéro coupe
le son, remonter le curseur le réactive.

Cliquer Écouter la mélodie d'essai, puis Écouter le son d'effet. La mélodie dure
1,6seconde, l'effet0,35seconde ; recliquer pour réécouter après un réglage.
Vérifier qu'Effets à0 coupe l'effet mais garde la mélodie, Musique à0 fait
l'inverse, et Général à0 coupe les deux. Monter les curseurs pour retrouver
les sons. Le bouton Arrêter et la fermeture du menu arrêtent les essais.
Les échantillons sont originaux, synthétisés pour calibrer les réglages :
ce ne sont pas les musiques ni bruitages finaux. Leur provenance est dans
LABORATORY_AUDIO.md. En vitesse4×, la mélodie garde sa hauteur et sa durée.
L'écoute réelle attend ton retour Windows ; les tests techniques vérifient
les données, lecteurs, gains et bus sans prétendre écouter à ta place.

CHANGER LES TOUCHES
Cliquer Interagir / texte suivant puis appuyer sur F, par exemple. Fermer le
menu et vérifier que F permet d'interagir avec le guide et d'avancer ses
textes. La même touche sert aux messages de combat et aux cinématiques.
L'ancienne E ne doit plus avancer les textes après cette modification.
Une touche maintenue ne doit pas passer plusieurs phrases automatiquement.
Entrée/Espace restent disponibles pour confirmer les interfaces, ainsi que
l'ancienne confirmation A dans les textes. Échap garde toujours le retour.

Changer ensuite Aller à gauche, par exemple vers K : cette touche remplace
les anciens alias de cette action, elle ne s'ajoute pas aux trois touches.
Un conflit avec une autre commande est refusé, y compris ses valeurs par
défaut. Les touches réservées (Échap, Entrée, Espace, F3) sont refusées pour
une nouvelle affectation. Lettres physiques A–Z, chiffres, flèches, Tab,
Maj/Ctrl sont proposées dans ce premier bloc ; pas de combos ni de manette.
Échap pendant la saisie annule le changement et laisse les paramètres ouverts.
La touche de Menu peut changer, mais Échap reste toujours disponible.

Les touches sont PHYSIQUES : la position du clavier prévaut pour éviter de
changer le comportement en passant AZERTY/QWERTY. Les noms affichés suivent
les codes physiques Godot ; ils peuvent donc différer de la lettre imprimée.
Les flèches et les alias de déplacement initiaux sont conservés tant qu'une
action n'a pas été reconfigurée. Le reset restaure seulement les touches,
sans changer les volumes, la taille du texte, la langue ou la caméra.

CONSERVER LES RÉGLAGES

Fermer et relancer l'EXE : volumes, texte et touches doivent revenir. Charger
une ancienne partie ou un autre emplacement ne doit pas les modifier.
Vérifier ce point avec une sauvegarde existante, sans recommencer l'aventure.
