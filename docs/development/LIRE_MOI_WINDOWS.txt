INSTALLATION ET BLOCAGE WINDOWS
Décompresser entièrement le ZIP dans un dossier, puis ouvrir
Archelys-Laboratoire.exe. Aucune installation de Godot n'est nécessaire.
Il s'agit d'un prototype Windows 64 bits, pas d'une ROM.
Cette variante portable contient un moteur Godot non modifié et un fichier
Archelys-Laboratoire.pck séparé contenant le jeu. Garder les deux fichiers
dans le même dossier ; ne pas lancer l'EXE depuis l'intérieur du ZIP.
Aucune signature reconnue ni autorisation Windows n'est ajoutée.
Le Contrôle intelligent des applications peut donc encore bloquer le lancement.

PREMIER TEST DE CETTE LIVRAISON
Essayer d'abord de lancer normalement Archelys-Laboratoire.exe, sans modifier
les réglages de sécurité Windows. Si Windows le bloque encore, noter simplement
« lancement bloqué par le Contrôle intelligent » : les tests en jeu attendront.
S'il démarre, vérifier le parcours complet ci-dessous. Le propriétaire a
confirmé que la variante portable précédente lançait le jeu sans avertissement
sur son PC. Le moteur de ce build reste identique ; les données ont évolué.


Si l'écran indique « Windows a protégé votre ordinateur » et propose
« Informations complémentaires », cliquer dessus puis « Exécuter quand même »
si tu choisis d'exécuter ce build téléchargé depuis la release du dépôt.
Une autre possibilité, quand Windows la propose : clic droit sur le fichier,
Propriétés, cocher « Débloquer », puis Appliquer. Cela ne signe pas le programme.

Ces options ne sont pas disponibles dans tous les cas. Smart App Control,
une politique d'entreprise ou une détection antivirus sont des situations
différentes : ne pas désactiver globalement la protection. Dans ce cas, noter
le texte exact de l'écran et le nom de la protection pour diagnostiquer le blocage.

Une signature reconnue exige un certificat de signature de code ou un service
de signature autorisé. Aucun n'est configuré pour ce projet actuellement.
Une signature auto-signée ne suffit pas pour être reconnue sur ton PC.

CE QUI CHANGE DANS CE LOT
Langue des dialogues et distance caméra enregistrées automatiquement.
Elles restent conservées au chargement et au relancement du jeu.
Le bouton de langue indique désormais la langue sélectionnée.
Interactions avec un guide, un panneau et une caisse.
Sac de test avec un jeton ; la caisse ne le donne qu'une seule fois.
Journal avec trois objectifs de laboratoire, persistants dans la campagne.
Lecture des sauvegardes anciennes et copie originale conservée avant conversion.
Moteur portable identique ; aucun achat de certificat ni changement de Windows.
Ce sont des systèmes de test : pas le scénario final, pas un catalogue d'objets
Pokémon terminé, pas encore un moteur de combat 9G.

PARCOURS DE TEST DU LOT — UN SEUL RETOUR POUR L'ENSEMBLE

PRÉFÉRENCES — passer les dialogues en anglais et ajuster la caméra.
Charger la partie : les choix actuels doivent rester conservés.
Fermer complètement le jeu puis le rouvrir : anglais et distance choisie doivent
revenir automatiquement, avant même de charger une campagne.
La langue concerne les dialogues et le panneau journal/sac ; toute l'interface
n'est pas encore traduite. La phrase déjà ouverte garde sa langue jusqu'à la fin.

EXPLORATION — E ou Entrée près d'un objet ouvre son interaction.
Guide à droite du départ ; panneau au nord-ouest (-3,-3) ; caisse au sud-est (6,6).
Les coordonnées servent seulement à repérer les objets dans ce laboratoire.
À distance, E ne doit rien ouvrir. Le personnage s'arrête pendant les textes.
Une phrase doit attendre une nouvelle pression ; maintenir la touche ne doit
pas faire défiler toutes les phrases. Après fermeture, le déplacement reprend.

JOURNAL — terminer les trois phrases du guide, puis lire les deux du panneau.
Leurs objectifs passent de cercle à coche. Ouvrir la caisse complète le troisième.
Le journal est une mini-boucle technique, sans engagement sur le scénario final.

SAC — la caisse ajoute exactement un jeton de test et devient plus sombre.
L'ouvrir à nouveau affiche qu'elle est vide ; le sac doit rester à un jeton.
Le jeton n'est pas utilisable : il sert à éprouver récompenses et persistance.

SAUVEGARDE — après les objectifs, cliquer Sauvegarder, puis marcher ailleurs.
Cliquer Charger : retrouver position, coches du journal et jeton.
Fermer puis rouvrir le jeu et cliquer Charger : retrouver aussi ces états.
Rouvrir la caisse après chargement ne doit pas donner un second jeton.
La campagne ne se charge pas automatiquement au lancement ; les préférences, oui.

ANCIENNE SAVE — si tu avais une sauvegarde du laboratoire précédent, la charger
sans l'effacer : position et palier restent, journal/sac nouveaux sont vides.
Le format devient version 2 lors de ta prochaine sauvegarde. Une copie originale
version 1 est conservée dans laboratory_campaign.json.v1.backup.
Les anciens builds ne savent pas lire la nouvelle version 2 ; utiliser cette
copie pour revenir en arrière, en préservant d'abord tes fichiers.

COMBAT ET FLUIDITÉ — vérifier rapidement le duel factice et son reset,
le déplacement ZQSD/WASD/flèches et les obstacles. Caméra suivie et réglable.
Le duel reste transitoire ; aucun test de mécaniques Pokémon complètes demandé.

AUCUN TEST MULTIJOUEUR DEMANDÉ. Ne pas passer du temps sur connexion,
copies de sauvegardes ou trois fenêtres. L'ancien essai, s'il est affiché,
reste limité à localhost ; connexions entre PC et Internet non validées.
