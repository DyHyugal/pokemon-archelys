INSTALLATION ET BLOCAGE WINDOWS
Décompresser entièrement le ZIP dans un dossier, puis ouvrir
Archelys-Laboratoire.exe. Aucune installation de Godot n'est nécessaire.
Il s'agit d'un prototype Windows 64 bits, pas d'une ROM.
Cette variante portable contient un moteur Godot non modifié et un fichier
Archelys-Laboratoire.pck séparé contenant le jeu. Garder les deux fichiers
dans le même dossier ; ne pas lancer l'EXE depuis l'intérieur du ZIP.
Aucune signature reconnue ni autorisation Windows n'est ajoutée.
Le Contrôle intelligent des applications peut donc encore bloquer le lancement.

PREMIER TEST DE CETTE LIVRAISON
Essayer d'abord de lancer normalement Archelys-Laboratoire.exe, sans modifier
les réglages de sécurité Windows. Si Windows le bloque encore, noter simplement
« lancement bloqué par le Contrôle intelligent » : les tests en jeu attendront.
S'il démarre, vérifier le parcours complet ci-dessous. Le propriétaire a
confirmé que la variante portable précédente lançait le jeu sans avertissement
sur son PC. Le moteur de ce build reste identique ; les données ont évolué.


Si l'écran indique « Windows a protégé votre ordinateur » et propose
« Informations complémentaires », cliquer dessus puis « Exécuter quand même »
si tu choisis d'exécuter ce build téléchargé depuis la release du dépôt.
Une autre possibilité, quand Windows la propose : clic droit sur le fichier,
Propriétés, cocher « Débloquer », puis Appliquer. Cela ne signe pas le programme.

Ces options ne sont pas disponibles dans tous les cas. Smart App Control,
une politique d'entreprise ou une détection antivirus sont des situations
différentes : ne pas désactiver globalement la protection. Dans ce cas, noter
le texte exact de l'écran et le nom de la protection pour diagnostiquer le blocage.

Une signature reconnue exige un certificat de signature de code ou un service
de signature autorisé. Aucun n'est configuré pour ce projet actuellement.
Une signature auto-signée ne suffit pas pour être reconnue sur ton PC.

CE QUI CHANGE DANS CE LOT
Menu Pause avec Sac, Journal, Paramètres, Sauvegarder et Charger.
Le Sac affiche le jeton reçu, sa quantité et sa description.
Distance caméra disponible dans Paramètres, conservée automatiquement.
Langue FR/EN des menus et dialogues ; préférences indépendantes de la campagne.
Écran de jeu dégagé ; outils du laboratoire masqués, accessibles par F3.
Le format de sauvegarde reste version 2 ; anciennes sauvegardes lisibles.
Le jeton et les objectifs sont du contenu technique, pas le catalogue final.

PARCOURS DU LOT — UN SEUL RETOUR POUR L'ENSEMBLE

MENU — Échap ouvre Pause ; clic sur Menu fonctionne aussi.
Choisir les pages à la souris ou avec Tab puis Entrée.
Échap revient à Pause depuis une page ; une seconde pression reprend le jeu.
I ouvre directement le Sac ; J ouvre le Journal, hors dialogue.
Déplacement et interactions du monde doivent rester bloqués dans les menus.
À la fermeture, le déplacement doit reprendre normalement.

SAC — Charger ta sauvegarde via le menu. Si tu avais reçu le jeton,
ouvrir Sac : « Jeton de test × 1 » et une description indiquant quantité 1.
Sinon, le sac indique qu'il est vide. Aller à la caisse au sud-est (6,6),
appuyer E ou Entrée pour l'ouvrir, puis consulter le Sac avec I.
Rouvrir la caisse : toujours un seul jeton ; aucun bouton Utiliser,
car cet objet sert seulement au test de récompense et de persistance.

JOURNAL — Parler au guide à droite, lire le panneau au nord-ouest (-3,-3),
ouvrir la caisse. Le Journal affiche les coches correspondantes.
Chaque phrase attend une nouvelle pression E / Entrée ; une touche maintenue
ne doit pas tout passer. Échap ne coupe pas une conversation active.

PARAMÈTRES — Choisir anglais, rapprocher puis éloigner la caméra avec le curseur.
Les menus et prochains dialogues changent de langue. Fermer le menu pour voir
la nouvelle distance. Charger la partie : ces préférences restent conservées.
Fermer complètement le jeu puis le relancer : langue et caméra sont conservées,
même avant le chargement d'une sauvegarde.

SAUVEGARDE — Sauvegarder dans le menu après avoir reçu le jeton et validé
les objectifs. Marcher ailleurs puis Charger : position, jeton et coches restaurés.
Fermer/reprendre le jeu et Charger : vérifier la même chose.
La campagne n'est pas chargée automatiquement ; les préférences le sont.

RÉGRESSION COURTE — Déplacements ZQSD/WASD/flèches et obstacles.
F3 ou Outils labo affiche les boutons du duel factice et de reset.
Le combat reste une simulation technique, sans règles Pokémon complètes.
Aucun test multijoueur demandé ; connexion et sauvegardes multi reportées.
