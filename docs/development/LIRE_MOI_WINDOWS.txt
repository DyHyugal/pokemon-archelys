INSTALLATION ET BLOCAGE WINDOWS
Décompresser entièrement le ZIP dans un dossier, puis ouvrir
Archelys-Laboratoire.exe. Aucune installation de Godot n'est nécessaire.
Il s'agit d'un prototype Windows 64 bits, pas d'une ROM.
Cette variante portable contient un moteur Godot non modifié et un fichier
Archelys-Laboratoire.pck séparé contenant le jeu. Garder les deux fichiers
dans le même dossier ; ne pas lancer l'EXE depuis l'intérieur du ZIP.
Aucune signature reconnue ni autorisation Windows n'est ajoutée.
Le Contrôle intelligent des applications peut donc encore bloquer le lancement.

PREMIER TEST DE CETTE LIVRAISON
Essayer d'abord de lancer normalement Archelys-Laboratoire.exe, sans modifier
les réglages de sécurité Windows. Si Windows le bloque encore, noter simplement
« lancement bloqué par le Contrôle intelligent » : les tests en jeu attendront.
S'il démarre, vérifier le parcours complet ci-dessous. Le propriétaire a
confirmé que la variante portable précédente lançait le jeu sans avertissement
sur son PC. Le moteur de ce build reste identique ; les données ont évolué.


Si l'écran indique « Windows a protégé votre ordinateur » et propose
« Informations complémentaires », cliquer dessus puis « Exécuter quand même »
si tu choisis d'exécuter ce build téléchargé depuis la release du dépôt.
Une autre possibilité, quand Windows la propose : clic droit sur le fichier,
Propriétés, cocher « Débloquer », puis Appliquer. Cela ne signe pas le programme.

Ces options ne sont pas disponibles dans tous les cas. Smart App Control,
une politique d'entreprise ou une détection antivirus sont des situations
différentes : ne pas désactiver globalement la protection. Dans ce cas, noter
le texte exact de l'écran et le nom de la protection pour diagnostiquer le blocage.

Une signature reconnue exige un certificat de signature de code ou un service
de signature autorisé. Aucun n'est configuré pour ce projet actuellement.
Une signature auto-signée ne suffit pas pour être reconnue sur ton PC.

PARCOURS UNIQUE — UN SEUL RETOUR POUR CE LOT

REPRENDRE — Charger ta partie précédente. Échap ouvre le menu ; molette dans
le contenu et la navigation si nécessaire. I = sac, J = journal.
Le village/équipe précédent est conservé. Débloquages et prix sont des données
techniques provisoires, pas l'équilibrage final. Les sauvegardes 1/2/3 sont lues.

SERVICES — Village : porte maison gauche (-8,2) = Centre, droite (8,2) = boutique.
E / Entrée à proximité pour entrer. Les objets/PNJ peuvent bloquer le passage,
interagir en restant devant ; ce n'est pas nécessaire de marcher sur leur centre.
Dans l'intérieur, comptoir au nord (0,-3) : E / Entrée. Acheter une Potion puis
cinq, vendre une ; vérifier sac et argent. Une tentative trop chère doit ne rien
modifier. Une transaction est disponible uniquement dans la boutique.
Au Centre, soigner puis vérifier PV, PP et statuts. L'exit au sud (0,7) retourne
au village. Sauvegarder dans un intérieur, relancer et Charger : intérieur correct.

EXPLORATION — Passage sud (0,9) = crique. Jetée / fish (0,-3) : E lance une
rencontre de pêche ; mêmes commandes de capture/fuite que dans les herbes.
Au cap initial : Magicarpe ; dès niveau 20 : Léviator, pas une forme sous-évoluée.
Surf : point (4,-3), nécessite première victoire contre le dresseur 1.
Avant : accès à l'eau bloqué ; après : déplacement sur l'eau sans Pokémon
compatible. Quitter la crique remet le mode Surf à zéro.
Dans le village, Coupe à gauche (-11,3), Éclate-Roc à droite (11,3), Force (11,6).
Interagir retire le blocage. Force attend la première victoire.
Escalade (-11,8) : même condition, accès au promontoire puis E pour redescendre.
Flash est autorisé dès le début ; pas encore de grotte sombre à tester.

CARTE / VOL — Visiter d'abord crique et quartier via leurs passages.
Vaincre le dresseur 1 ; Échap → Carte / Vol permet de voler vers village/crique/
quartier déjà visité, même avec l'équipe Bulbizarre/Salamèche/Carapuce.
La carte présentée est une navigation technique, pas l'archipel final dessiné.
Une destination non visitée doit rester bloquée.

RÈGLES — Échap → Règles / Difficulté : chill, normal, hard ; plafond de niveau,
EXP et chance shiny. OFF permet de dépasser le cap ; réactiver conserve les
niveaux dépassés, sans gagner d'EXP tant que le cap ne les rattrape pas.
F3 → entraînement donne de l'EXP pour tester sans grind. Paramètres propose
1×/2×/3×/4× provisoires ; maintenir E ne doit toujours pas passer tous les textes.
EXP et shiny concernent les générations/gains à venir, pas les individus déjà créés.
Sauvegarder/charger doit garder les règles ; langue/caméra/vitesse restent séparées.

MÉGA ET IA — F3 affiche les outils du laboratoire (faire défiler le panneau).
« Kit Méga » donne Florizarre/Dracaufeu/Tortank niveau 36 et les pierres pour
essais ; équipe pleine = PC. Les ajouter en équipe puis placer l'un en tête.
Le kit relève le cap pour éviter le grind ; il ne valide ni starters ni récompenses.
Résumé : CT gratuites réutilisables et choix de talents légaux.
Combat → Attaquer : cocher Méga, choisir l'attaque. Transformation pour ce combat,
une seule Méga de l'équipe, même si elle finit KO. Après combat, forme ordinaire.
F3 → Essai soleil : Feunard pose le soleil, passe normalement à Florizarre,
rappelle un poseur si le soleil expire ; Goupix est le second poseur disponible.
Un KO certain peut passer avant le retrait du poseur. L'essai terrain utilise
Raichu poseur → Pikachu bénéficiaire → second Raichu poseur.
Ces boutons activent hard pour cet essai. Vérifier le compteur de champ/climat,
la remise en place avant un nouveau DPS et l'absence de boucle de changements.
L'IA ne lit pas ta prochaine action ni tes IV/EV/nature/objet/attaques non révélées.
C'est une politique de laboratoire à éprouver, pas une IA finale universelle.

DOUBLES — Au moins deux membres aptes ; F3 → Essai combat double.
Choisir attaque + cible pour le premier membre puis pour le second : les deux
choix se verrouillent avant la résolution globale du tour. Quatre fiches de PV.
Tester des cibles différentes, changement vers le troisième membre, KO/remplaçant.
Deux positions ne doivent pas réserver le même remplaçant. Un seul compteur
climat/terrain par tour. Catalogue actuel mono-cible ; objets, zone, redirection,
Abri, raids et gestion avancée des poseurs en doubles ne sont pas encore couverts.
Un combat double est solo ici ; aucun test de connexion demandé.

DÉFI NUZLOCKE — Essai facultatif. Sauvegarder une copie normale AVANT activation
pour pouvoir revenir à ce point de test. Activation dans Règles / Difficulté.
Un essai de capture par zone : premier échec de Ball, fuite ou KO engage le quota.
Les doublons familiaux peuvent être ignorés ; si tu choisis de lancer une Ball sur
un doublon avec quota libre, elle engage ce quota. Clause shiny : capture et usage
hors quota, résultat shiny fixé à la génération. KO permanent : Centre et soins
ne ressuscitent pas. Les Pokémon encore vivants dans le PC empêchent le game over.
Défi désactivable définitivement ; pas de bouton pour le réactiver sur cette partie.
Passer en normal permet les soins. Reprise avec Chapignon, cadeaux/œufs/fossiles
et Soul-link sont à compléter ; la règle des nouveaux quotas attend ton choix.
Le kit technique Méga est interdit tant que le défi est actif.

COMPARATIF GRAPHIQUE — Passage nord du village (0,-9) = quartier visuel.
Au point « visuals » (0,3), E passe de A à B à C. Aucune variante n'est finale.
A : côtier sobre / deux pans ; B : chaleureux / cheminée ; C : toit plat / auvent.
Le ZIP contient aussi trois captures FHD dans Comparatifs.
Choisir A/B/C/aucune et préciser séparément maison, arbres, eau, chemins et relief.
C'est une proposition de matériaux/modules, pas une île de qualité finale : eau
et raccords/ombres/volcan restent à travailler après choix artistique.
Le mannequin animé est le modèle de test antérieur ; pas de modèles Pokémon.
