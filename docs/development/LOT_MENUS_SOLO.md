# Bloc menus solo

Objectif : consulter réellement le jeton dans le Sac et conserver le réglage caméra dans les Paramètres (D45), après validation propriétaire de lab-e84ee99 (D44).

Pause ouvre Sac, Journal et Paramètres ainsi que Sauvegarder/Charger. Le sac présente quantité et description, ou indique qu'il est vide ; l'objet témoin reste non utilisable. Journal et inventaire se mettent à jour après chargement. Les menus sont FR/EN, réglages enregistrés automatiquement. Les outils factices restent disponibles avec F3, masqués dans le parcours ordinaire.

Échap ouvre Pause ; depuis une page revient à Pause, puis ferme. I/J ouvrent Sac/Journal. Les contrôles natifs supportent souris et Tab/Entrée. Le personnage s'arrête dès l'ouverture et aucune interaction du monde ne passe à travers. Les dialogues actifs restent prioritaires.

Aucune dépendance supplémentaire ni changement de schéma de campagne/préférences. Sauvegardes précédentes utilisables, service et copies de migration conservés. L'EXE reste le moteur portable officiel inchangé ; seules les données PCK évoluent.

Contrôles exécutés avec succès ([log](validation/menu-checks.log)).
