# Assets du laboratoire

`mannequin.glb` est un mannequin original produit par `tools/create_prototype_avatar.py` avec Blender 4.3.2, matériaux simples, un rig de sept os et une animation de marche. Il ne représente aucun Pokémon ni personnage officiel. Il sert à vérifier le pipeline d’import, pas à fixer le style final.

Les maisons, arbres et reliefs du laboratoire sont générés par le code original de la scène. Aucun asset extrait d’un jeu ou bibliothèque tierce n’est inclus. La licence générale des créations du projet reste une décision du propriétaire ; ne pas déclarer ces contenus CC0 sans cette décision.

Le glTF est non compressé ; le message Blender concernant l’absence de Draco n’empêche pas cet export. L’import et l’exécution de l’animation sont vérifiés dans le test `asset_import.gd`.
